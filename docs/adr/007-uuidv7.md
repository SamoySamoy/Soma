# 007. UUIDv7 primary keys

- Status: Accepted
- Date: 2026-10-04

## Decision

Primary keys are UUIDv7, generated by PostgreSQL 18's `uuidv7()`.

## Consequences

Time-ordered keys keep B-tree indexes compact and make cursor pagination
cheap. IDs are safe to expose and keep their identity when a `.soma` package
moves between instances.
